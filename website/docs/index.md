# EZInfiniteYTLive documentation

Welcome to the EZInfiniteYTLive documentation. This project is a small Windows desktop tool that uses FFmpeg to loop a folder of videos into a continuous RTMP livestream.

Use the sidebar to find installation and usage instructions, an architecture overview, configuration details, and an API reference for the C# codebase.
